# Brand onboarding

Start from user-provided company name, official website address, and optionally a local logo file. Create one profile per brand, then have the brand owner review aliases, countries/TLDs, risk vocabulary, allowlist, official infrastructure, and logo fingerprint before enabling monitoring.

An address establishes a monitoring target only; it does not prove legal ownership. A supplied name alone has lower discovery quality. A remote logo URL is not a local asset: do not download it automatically; ask for a local file or separately authorized capture.
